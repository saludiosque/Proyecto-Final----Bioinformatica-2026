# Proyecto-Final----Bioinformatica-2026
Workflow reproducible en Galaxy y Google Colab para control de calidad, alineamiento y análisis de datos de secuenciación.

Para reproducir este Workflow acceder al siguiente link: https://usegalaxy.eu/published/workflow?id=81de44a1f641fb12


Los datos necesarios para realizar el proyecto se encuentran disponibles en el repositorio. Desde SRA en NCBI es posible acceder a los archivos FASTQ de las secuencias con el id de proyecto Accession: PRJNA1132966 ID: 1132966


Para acceder al genoma de referencia utilizado apra alinear las secuencias acceder al SRA de NCBI con el id: GCA_011075055.1 Genome assembly CATAS_Mindica_2.1
